# API Films

API REST simples desenvolvida com Hono sobre Node.js.

## Como rodar

```bash
npm install
npm start
```

Modo dev:
```bash
npm run dev
```

Servidor: `http://localhost:8080`

## Rotas

### GET /api/filmes
Retorna a lista de filmes.

Exemplo de chamada:
```bash
curl http://localhost:8080/api/filmes
```
